# PCでの確認手順（ようさん用）

Unity版がいちばん詰まっているのは「実際にUnityで開いて動くか」の確認です。
ここだけはGPUのあるWindows PCでしかできません。この手順どおりに進めてください。
分からなくなったら、その画面のスクショをミューズに送れば続きを案内します。

## 準備（初回だけ）

1. **Unity Hub** を入れる（https://unity.com/ja/download ）
2. Unity Hub の Installs から **Unity 6.3 LTS（6000.3.29f1）** を入れる
   - そのとき **Windows Build Support** にチェックを入れる
   - 見つからない場合は、少し前後の 6000.3.x でも開けます（バージョン違いの警告が出たら
     「続ける」で進めてください。その旨をミューズに教えてください）
3. このリポジトリを PC に持ってくる
   - GitHub の `dosumonosuke/Criminal_story` ページで、緑の **Code** ボタン →
     **Download ZIP** → 解凍するのが一番簡単です

## 素材を取り直す（GitHub版には画像素材が入っていません）

4. 解凍した中の `unity` フォルダにある **fetch-assets.ps1** を実行する
   - ファイルを右クリック →「PowerShell で実行」
   - 止められた場合は、PowerShell を開いて `unity` フォルダへ移動し、
     `powershell -ExecutionPolicy Bypass -File .\fetch-assets.ps1` を実行
   - 終わると、空のHDRIと質感テクスチャ4種が自動で入ります（すべてCC0・無料）

## Unityで開く

5. Unity Hub の「開く」から、`unity` フォルダを選ぶ
   - 初回は読み込みに数分〜十数分かかることがあります。固まったと思っても待ってください
6. 開けたら、下の **Console** タブを見る
   - **赤いエラー**が出ていたら、その全文のスクショをミューズに送ってください（ここが最重要）
   - 黄色の警告だけなら、まず進めて大丈夫です
7. HDRP（画質の方式）の割り当ては `unity/README.md` の
   「HDRPを有効にする手順」が入口です。最初は割り当てなしでも再生はできます
   （その場合、見た目は仮のものになります）

## 再生して確認する

8. `Assets/Scenes/Main.unity` を開き、上の **▶（再生）** を押す
9. 次の順で見えているか確認してください（チェックリスト）

   - [ ] 病院の病室が出る（ベッド、母親、医師、看護師）
   - [ ] 人物に名札が出ている（医師／看護師／母親ダイアン と分かる）
   - [ ] 最初は視界がぼやけていて、少しずつ開けてくる
   - [ ] セリフが下に出て、クリック／スペースで次へ進む
   - [ ] 「女の子です」「1956年2月29日、ミシガン州ロチェスター」のセリフが出る
   - [ ] 暗転して、ミシガンの町（住宅街）へ移る
   - [ ] 家・店・車・街灯・信号・木がある。地面や道路が単色ではない
   - [ ] 歩いている人と、祖母・祖父・兄キースがいる
   - [ ] 画面に「祖母に近づく」目的と、残りの距離が出る
   - [ ] 祖母の近くで **E** を押すと会話が始まる
   - [ ] 会話が終わると完了のパネルが出る

10. Game画面の **Stats** ボタンを押すと FPS（滑らかさの数字）が出ます。
    その数字も教えてください

## ミューズに送ってほしいもの

- Console の赤いエラー（あれば全文のスクショ）
- 再生中のスクショ 3枚：第0章の病室／町／祖母との会話
- FPS の数字
- チェックリストで ✗ になった項目

これが届けば、直す作業はミューズ側で全部やります。
