# Steamへの出し方（メモ）

## 現在の状態

- 試作版は HTML5（`game/index.html`）で動作します。ブラウザでそのまま遊べます。

## Windows / Steam 向けの進め方（次の段階）

1. このHTML5版を Electron などで Windows アプリ（.exe）として包むか、
   Godot へ移植して Windows 向けに書き出す。
2. Steamworks Partner に登録する（ようさん本人のアカウントと、アプリ登録料が必要です）。
3. SteamPipe でビルドをアップロードし、ストアページを作成して審査を受ける。

## 注意

- Steamworks の登録・料金支払い・本人確認はミューズでは代行できません。
- 実在人物を扱うため、ストアページの説明文でも「事実に基づく再現であること」
  「犯罪を称賛する内容ではないこと」を明記する想定です。
