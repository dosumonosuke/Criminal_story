# 開発記録

## 2026-11-25

- 依頼：`Criminal_story` リポジトリに、Steamで遊べるゲームを作る。
  実在の犯罪者をモデルに、一人称視点で赤ちゃんから最期まで人生を再現する。
- 進め方の決定（ようさん指示）：モデルは世界中の極悪犯罪者からランダムに選ぶ。
  まずミューズが調べて1人分を試作し、そこから人数を増やしていく。
- 抽選：候補プール10人からプログラムでランダム抽選し、Aileen Wuornos を選定。
- 調査：Encyclopaedia Britannica などで生没年・経歴・逮捕・裁判・執行を確認。
  詳細は `docs/RESEARCH.md`。
- 実装：HTML5 のレイキャスティング方式で一人称ゲーム試作版 0.1 を作成。
  全8章、章ごとに視点の高さ（赤ちゃん→大人）と部屋の色が変わる。
  出口に触れると次の章へ進む。
- 次の予定：2人目を追加し、開始時のランダム選択を実装済み人物全体に広げる。
  Windows版（Steam向け）の書き出しはその後に行う。

## 2026-11-25（3D化：Godot 4 への土台切り替え）

- 方針変更（ようさん指示）：試作版0.1に「おもんない／人が出てこない／
  まわりが粘土／意味が分からない」と強い不満。さらに「GTA6みたいに
  グラフィックと町の様子を上げてほしい」との指示で、レイキャスター版の
  改善は中止し、本物の3D（Godot 4）へ切り替えることにした。
  ただしGTA級を目指すのは見た目と町の様子だけで、ゲーム本体は
  ストーリー主導（操作は場面の合間の限られた部分のみ、目的は常に1つ）に
  することも同日に確定。
- 追加指定：物語の始まりは「赤ちゃん編」ではなく「生まれてくる場面そのもの」
  から。第0章として病院の病室（医師・看護師・母親、赤ん坊視点で世界が
  少しずつ開ける演出）を冒頭に置き、その後に第1章→第2章へ続く構成にした。
  日時・場所は事実どおり 1956年2月29日・ミシガン州ロチェスター。
- 環境確認：この環境に Godot は入っていなかったため、公式GitHubリリースから
  Godot 4.3-stable（Linux版）をダウンロードして使用可能にした
  （`~/workspace/tools/godot/`、バージョン表示 4.3.stable.official で確認）。
- 実装（`godot/` フォルダ）：
  - シーンは `scripts/build_scenes.gd` が Godot 標準の3D形状とマテリアルから
    自動生成（外部アセット不使用。素材とライセンスは `docs/ASSETS_3D.md`）。
  - 第0章 `scenes/opening.tscn`：病室、ベッドの母親、医師、看護師、新生児ベッド、
    窓、ランプ、時計。白くぼやけた画面が約6秒で開け、セリフ6本が自動進行
    （クリック／スペースで送り可、視点は小範囲だけ移動可）。終了後、暗転して
    町へ自動遷移。
  - 町 `scenes/town.tscn`：住宅街1区画。交差点のある道路・横断歩道・歩道、
    家10軒、看板付き食料品店、街路樹、車5台、街灯、信号機、柵、郵便受け。
    空＋太陽光（影あり）＋軽い霧。人物NPCは歩く近所の人3名と祖父・兄キース・
    祖母（全員に名札）。目的は「祖母に近づいてEで話しかける」の1つだけで、
    距離表示付き。会話4行（第1〜2章の事実ベース）が終わると完了パネル表示。
- テスト結果：
  - ビルダー実行で両シーンの生成に成功（BUILD_OK）。
  - ヘッドレス起動（第0章・町とも）でスクリプトエラーなし。
    町シーンで起動時に1回だけ出る `mesh_get_surface_count` の
    "Parameter m is null" はヘッドレス用ダミーレンダラー側の警告で、
    全MeshInstanceにメッシュが割り当てられていることは .tscn を検査して確認済み。
  - Xvfb 上で実際に描画してスクリーンショット確認：第0章（医師・看護師・
    ベッドの母親・セリフ表示）、町（家並み・道路・歩くNPC・目的表示）とも
    意図どおり表示。初回撮影でスポーン直前に車が近すぎる問題と全体の
    白飛ばしが見つかり、車の配置変更と光・環境光の調整で修正済み。
  - 全編通し実行（第0章→町への自動遷移を含む）でもスクリプトエラーなし。
- 残っている課題：
  - 人物や建物はまだ基本形状の組み合わせで、GTA級の見た目には程遠い。
    次の段階で CC0 アセット（Kenney／Quaternius／Poly Haven 等）の導入と
    テクスチャ・HDRI の差し替えを進める（`docs/ASSETS_3D.md` に記録方針あり）。
  - Windows向け書き出しはプリセット（`godot/export_presets.cfg`）のみ用意。
    Export Templates のインストールと書き出し確認は Windows PC 側で行う。
  - 物語は第0章と町の導入会話のみ。第3章以降の3D場面は未着手。
- GitHub へは push していない（本体の確認待ち）。`game/index.html` は比較用に残置。

## 2026-11-25（Unity への切り替え：Unity 6.3 LTS + HDRP）

- 方針変更（ようさん指示）：制作エンジンを Unity に確定。さらに
  「グラフィックをもっと良く」「今ある技術で画質もクオリティも最大限に」
  との指示を受け、土台を次の前提で作り直した。Godot 版は参考用に残置。
- 前提：**Unity 6.3 LTS（6000.3.29f1）**、レンダリングは **HDRP 17.3.0**
  を第一候補（`unity/Packages/manifest.json`）。
  HDRP の DLSS／FSR1／FSR2／TAAU／STP とレイトレーシング対応は
  Unity 公式ドキュメントで確認済み（FSR 3 は対応表に無いため未確認扱い）。
- 実装（`unity/` フォルダ）：シーンは手作り YAML に頼らず、
  起動時に C# コードが世界を生成する方式。
  - `Assets/Scenes/Main.unity` は GameBootstrap だけの最小シーン。
  - Scripts 9本：起動組立、病院（第0章）とミシガン住宅街の生成、
    一人称操作、NPC（名札つき）、字幕UI、HDRP Volume
    （Bloom／ACES／色調整／ビネット／被写界深度／フォグ）、
    場面進行（第0章→町→祖母との会話→完了パネル）、脚本準拠のセリフ。
  - 第0章のぼやけは被写界深度で表現する設計（＋内蔵パイプライン用に
    白いヘイズのフォールバック併用）。
- 素材の実取り込み（すべて CC0、台帳 `unity/ASSETS.md`）：
  - Poly Haven の HDRI（Kloppenheim 06 Pure Sky、1K）を空に採用。
  - ambientCG の PBR 4セット（Asphalt006／Grass001／Bricks056 は
    4K原版を取得、PavingStones036 は 2K）。Color／NormalGL／Roughness を
    道路・芝生・壁・歩道／床に適用。リポジトリ容量のため取り込み用
    コピーは 2048px に縮小（原版への差し替え手順は unity/README）。
  - Kenney の ZIP はサイトのダウンロード方式のため自動取得できず未取得。
    Quaternius はライセンス（QAL）条件の保存が前提のため意図的に見送り。
    実写寄りの無料人物モデルは確認できるソースなし（現行人物は
    色・髪型・名札で判別可能にし、影も落とす。差し替え手順は README）。
- 検証：C# 全9ファイルは tree-sitter の C# 文法パーサーで構文検証OK。
  ただしこの環境に Unity エディタ／C# コンパイラは無く、型・API の
  最終確認と実描画（HDRP 割り当て、レイトレ、DLSS 等）は
  GPU 付き Windows PC で開いて行う必要がある（手順は unity/README）。
- GitHub へは push していない（本体の確認待ち）。
  注意：テクスチャ等のバイナリ素材（約21MB）は、従来のスナップショット
  push（UTF-8テキスト専用）では送れないため、push 方法は本体側で要判断。
