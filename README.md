# Criminal Story

Steamで遊べることを目標にした、一人称視点の人生再現ゲームです。

プレイヤーは、世界中の極悪犯罪者の中からランダムに選ばれた1人として生まれ、
赤ちゃんからスタートし、その人の実際の最期（死去／死刑執行／現在も収監中／釈放済み）
までを一人称でたどります。

## 3D版（Godot 4）― 現在の本命

試作版0.1（レイキャスター方式）へのフィードバックを受け、土台を
Godot 4 の本物の3Dに切り替えました。詳しくは `godot/README.md` を参照。

- 第0章「生まれる」：病院の病室で生まれる場面から開始（医師・看護師・母親が登場、
  赤ん坊視点で世界が少しずつ開けていく演出、セリフは自動で進行）
- 続いて第1〜2章の舞台であるミシガンの住宅街（町1区画）を歩ける試作
- 形式はストーリー主導：操作は場面の合間の限られた部分だけで、目的は常に1つ
- 下の試作版0.1（HTML）は比較用に残してあります

## 試作版 0.1（いま遊べる内容）

- 候補プール10人からランダム抽選を行い、1人目として
  **アイリーン・ウォーノス（Aileen Wuornos, 1956–2002、アメリカ）** を実装しました。
- 全8章：誕生（1956）→ 祖父母の家 → 少女期 → 放浪と最初の逮捕 →
  フロリダでの日々 → 事件の時期（1989–1990）→ 逮捕と裁判 → 死刑囚監房、そして最期（2002）
- 犯罪の手口や残虐な描写は扱いません。公開資料に基づく事実の要約で構成しています。
  出典は `docs/RESEARCH.md` を参照してください。

## 遊び方

1. `game/index.html` をブラウザで開く（インターネット接続は不要です）
2. 「人生をはじめる」を押す
3. 操作：W/A/S/D で移動、マウス（クリックでロック）または ←/→ で視点、
   各章の光る出口に触れると次の章へ進みます

## 候補プール（今後1人ずつ実装して増やします）

## Unity版の確認手順（PC用）

Unity版をWindows PCで開いて確認する手順は `docs/PC_VERIFICATION_GUIDE.md` にあります。
GitHub版には画像素材が入っていないため、手順の中にある `unity/fetch-assets.ps1` で
公式サイト（CC0）から自動で取り直します。

## Steamへの出し方

`docs/STEAM.md` に、Windows版として書き出す手順と Steamworks の注意点をまとめています。
Steamでの販売・公開には、ようさん本人の Steamworks アカウントと登録料が必要です
（ミューズ側では代行できません）。
